# Calculator

A responsive calculator for basic arithmetic.

## Features

- Addition, subtraction, multiplication, and division with standard operator precedence.
- Left-to-right evaluation for operators with the same precedence.
- Negative numbers, decimal values, and the `π` constant.
- Implicit multiplication with `π` and the previous answer (for example, `2π` and `3Ans`).
- Previous answer saved in the browser for later calculations with `Ans`.
- Keyboard and on-screen button input.
- Results rounded to 12 significant digits. Invalid input and non-finite results show an error.

## Use

Open `index.html` in a browser, or visit the [Calculator](https://abdaltwabsayed.github.io/Calculator/).

Use the on-screen buttons or your keyboard:

- `0`–`9` and `.` enter numbers.
- `+`, `-`, `*`, and `/` enter operators.
- `Enter` calculates the result.
- `Backspace` deletes the last entry, and `Escape` clears the display.

Press an operator after a result to continue calculating with it. Use `AC` to clear the display or `DEL` to delete the last entry.
